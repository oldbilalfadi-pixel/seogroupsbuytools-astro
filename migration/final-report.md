# Pages CMS conversion — verification report

## Coverage
- 72 original JSON content records retained: 1 homepage, 30 product pages and 41 other pages (including the existing 404 source).
- Existing HTML, styles, responsive behavior, URLs, checkout destinations, pricing and images are retained as immutable originals unless edited in CMS.
- The Astro static build produces 71 published pages; the existing 404 source entry is not a public route.
- CMS groups contain editable text, headings, features, FAQ answers, table content and labels. Product editors include product title, short description, main price, image, buying link and trust features.
- Shared navigation/footer, visual card links, prices, hero, images, and SEO fields are connected to the renderer.
- Technical source fields used for precise rendering are hidden in Pages CMS. The schema enables settings.content.merge so unmanaged JSON is not dropped.

## Verification
- GitHub Actions workflow `Verify Pages CMS 72 pages` checks preservation of untouched HTML across all 72 records and changes to representative fields for products, prices, images, links, section headings, FAQ-like content, SEO, hero and shared chrome.
- GitHub Actions `Astro build test` compiles Astro routes.
- `Live vs preview parity audit` and `Browser visual parity audit` are separate workflow checks.
- The full list of original sections and editable field counts is generated by `node scripts/report-cms.mjs`.

## Limitations
- Pages CMS is a structured form editor, not Elementor or a drag-and-drop website designer.
- This validation is based on repository files, generated output and automated workflow checks; an authenticated Pages CMS save-and-reload test in the hosted CMS is not included.
- No manual Cloudflare deployment was performed by these scripts; hosting deployment triggers configured elsewhere may act automatically.
